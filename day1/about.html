About QuickNotes

QuickNotes is a lightweight app for capturing ideas as they come to you. It is designed to stay out of your way so you can write first and organise later.

How to use QuickNotes

  1. Click "New Note" to start a blank note.
  2. Type your idea into the editor.
  3. Press Save to store the note for later.

Features

  • Instant note creation
  • Offline access
  • Full-text search
  • Keyboard shortcuts

Keyboard shortcuts

Shortcut Action
Ctrl + N New note
Ctrl + S Save note
